# Семейный план безопасности

Простая страница, в которой семья за полчаса составляет свой план действий на случай пожара, землетрясения, утечки газа и других неприятностей. План можно распечатать или сохранить в PDF и повесить у двери.

## Что внутри

- экстренные номера (по умолчанию для Кыргызстана, их можно исправить)
- адрес и контакты, кому звонить
- места встречи рядом с домом и вдали от него
- данные о здоровье: группа крови, аллергии, лекарства
- проверка безопасности дома и список для тревожного чемоданчика
- кодовое слово для детей
- короткие памятки: пожар, землетрясение, запах газа

## Как пользоваться

1. Скачайте файл `index.html` и откройте его в браузере. Интернет не нужен.
2. Заполните поля вместе с семьёй.
3. Нажмите «Распечатать или сохранить в PDF».

Чтобы страница открывалась по ссылке, включите GitHub Pages: Settings → Pages → Branch `main` → Save.

## Приватность

Всё, что вы вводите, хранится только в вашем браузере на вашем устройстве. Страница ничего никуда не отправляет и не использует внешних сервисов.

## Важно

Это памятка, а не замена инструкциям спасательных служб. Проверьте экстренные номера для своей страны и региона.
